Чтобы добавить товар — скопируйте один объект и заполните:
id       — уникальный идентификатор (любая строка)
category — категория раздела (см. допустимые значения ниже)
name     — название товара
desc     — краткое описание (1–2 предложения)
price    — цена в рублях (число)
image    — путь к фото в папке images/ (например: "images/tshirt.jpg")
badge    — необязательный ярлык (например: "Хит", "Новинка", "–20%")
inStock  — true / false


Допустимые значения category:
Одежда:    
"men"     — мужское
"women"    — женское
Инвентарь: 
"home"    — для дома
"gym"      — для зала
Питание:   
"protein" — протеин 
"recovery" — восстановление
